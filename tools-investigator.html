Tools Investigator — Generador One-Liner

Generador interactivo de comandos One-Liner para investigación y peritaje forense en cPanel, DirectAdmin, Linux Genérico y Windows Server.

VERSIÓN 2.5
COMANDO ONE-LINER RESULTANTE
python3 <(wget -qO- https://raw.githubusercontent.com/caap1234/Chamba/main/investigators/01_abuse_mail_investigator.py)
Ejecución directa en memoria vía pipe. No requiere clonar el repositorio ni guardar archivos en disco.

01. Abuse Mail Investigator

Auditoría de envíos salientes en Exim, Dovecot (IMAP/POP3), cwd de scripts PHP y rastreo de envíos desde Webmail (127.0.0.1) vía cabecera X-Forwarded-For.

02. Web Access Investigator

Inspección forense de domlogs de Apache/Nginx para detectar webshells, peticiones POST y actividad alrededor de un compromiso.

03. Malware & File Investigator

Escaneo de webshells con firmas (eval, base64, passthru), cálculo de hashes MD5/SHA256, permisos 777 y persistencia en cron y SSH.

04. Account Access Investigator

Auditoría de inicios de sesión y acciones administrativas en cPanel, WHM, DirectAdmin y SSH.

05. Abuse Evidence Collector

Recolector técnico para generar el expediente estructurado con metadatos, hashes y líneas de log listo para copiar en el ticket de IRIS.

06. DNS & Domain Investigator

Resolución DNS (A, MX, SPF, DMARC), ASN de hosting, detección de proxies/CDNs y verificación de si apunta al servidor local.

07. Suspicious Activity Correlator

Timeline unificado: Cruza IP, usuario, domlogs web, envíos Exim, logins Dovecot y modificaciones de archivos en una sola línea de tiempo cronológica.

08. Windows Server Investigator

Auditoría de IIS W3C (.aspx, webshells), Eventos de seguridad (4624/4625), sesiones RDP, tareas programadas y SMTP en Windows.

09. Service Health & Exposure Check

Diagnóstico de procesos en /tmp, firmas de crypto-miners, conexiones salientes de spam directo (puerto 25) y salud operativa.

⚡ Investigator Suite & Hub (run_investigator.py)

Copia el comando de arriba y pégalo directamente en la terminal SSH del servidor para abrir el menú interactivo.
